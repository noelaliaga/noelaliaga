<h3>How I build</h3>

<p><b>Explicit permissions</b>: agents get an allowlist of what they may touch (see agent-crm-mcp, mcp-logistica).<br>
<b>Observable behavior</b>: write actions are logged where I have built the logging.<br>
<b>Independent review</b>: the session that writes a change does not approve it; a separate reviewer session checks a pinned commit.<br>
<b>Honest evaluation</b>: tests are reported with their counts and limits; synthetic demos are labelled as synthetic.<br>
<b>Durable context</b>: written handoffs and per-project context that outlive the session.</p>

<p><b>Note.</b> Repositories are separate components and experiments at different stages of maturity, not a single production-ready platform.</p>
